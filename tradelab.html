01 / PROJECT SCOPE & PROBLEM

How does a trading rule behave when you test it across the full market history?

Instead of showing a single profitable-looking chart, TradeLab exposes the parameters and lets the visitor rerun the strategy. Changing the moving-average windows can materially change trades, return and drawdown.

The project is deliberately a backtester rather than a claim of future profitability. It evaluates a simple rule on historical AAPL data and compares it against doing nothing except buying and holding.

02 / MY ROLE & SOLUTION

I built the strategy engine, transaction simulation, benchmark and animated browser visualizer.

Signal logic

A BUY signal occurs when the short moving average crosses above the long moving average; SELL is the opposite crossover.

Portfolio simulation

The strategy tracks cash, shares, entry/exit fees and mark-to-market equity without leverage or short selling.

Risk measurement

The simulator calculates strategy return and maximum drawdown as the backtest progresses.

Interactive visualizer

Run or step through the timeline to see the moving averages, crossover decision, trade markers and equity curve update.

03 / WORK PROCESS

Turn a trading idea into a testable algorithm.

01

Define the rule before seeing the result

The strategy uses a standard short-versus-long moving-average crossover instead of manually choosing profitable entry points.

02

Simulate execution

Each crossover changes the paper portfolio between cash and AAPL while transaction fees are deducted.

03

Benchmark the strategy

Strategy performance is shown beside buy-and-hold so the algorithm has a meaningful baseline.

04

Expose the parameters

The website lets the user change SMA windows and fees rather than hiding a single hand-picked configuration.

04 / OUTCOME & RESULTS

The result changes when the assumptions change — which is exactly the point.

TradeLab turns a static portfolio project into something a visitor can interrogate. You can make the strategy react faster, slower or become more expensive to trade, then immediately see the impact on return, drawdown and the number of trades.

What this project does not claim

Historical backtests can overfit and ignore many real-world effects. This project is an educational paper-trading simulator, not a live brokerage connection, trading recommendation or guarantee of future performance.

Historical monthly sample data ends in 2022. Educational use only — not financial advice.
